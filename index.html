    Logic Explanation

    The loot array holds one object for each item, and each object has a name and a value. The array is declared at the top of the script so it keeps its items between button clicks.

    For loop in getTotal() to add up every value in the array. Another for loop in renderLoot() to build one list item for each object.

    If statements check the inputs first. When adding loot, they make sure the name is not empty and the value is a number that is not negative. When splitting, they make sure the party size is a whole number and is >= 1 and that the array has loot. If the check fails, a message shows on the page and the function stops.
